# CHŁOPKÓW BOLONIA

Witaj w Chłopkowie. To krótka, pikselowa przygoda o wsi, którą najlepiej poznaje się noga po nodze: między domami, kościołem, polami i rzeką Melioranką.

Odkrywaj zakamarki, rozmawiaj z mieszkańcami i wypatruj wskazówek. Babcia Irenka prowadzi kronikę Chłopkowa i czeka na śmiałków gotowych zmierzyć się z quizem. Dziadek Zdzisiek ma swoje sprawy, a wioska skrywa małą tajemnicę.

Po drodze znajdziesz quiz o Chłopkowie oraz minigry dla tych, którzy wolą bieg, pościg i odrobinę zamieszania. Jest tu spokojnie... ale nigdy całkiem nudno.
